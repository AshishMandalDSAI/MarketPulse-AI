# MarketPulse AI — Model Documentation

## Trained Artifacts (`models/`)

| File | Description |
|---|---|
| `mmm_model.pkl` | Pickled dict: `{selected_model_name, model (sklearn Ridge), scaler (StandardScaler), feature_names, channel_params, control_cols, channels}` |
| `model_metrics.json` | Train/test R², adjusted R², RMSE, MAE, MAPE for all 3 compared models + which was selected |
| `model_diagnostics.json` | Residual diagnostics + per-channel adstock decay curves and saturation/response curves |

## Reproducing training

```bash
python src/data/generate_dataset.py
python src/data/data_cleaning.py
python src/features/feature_engineering.py
python src/models/marketing_mix_model.py
python src/models/model_evaluation.py
python src/models/channel_contribution.py
```

Each script is idempotent and safe to re-run; re-running `generate_dataset.py` with the default seed (42)
reproduces the exact same dataset.

## Model comparison (from the last verified run in this environment)

| Model | Test R² | Test RMSE | Test MAE | Test MAPE |
|---|---:|---:|---:|---:|
| baseline | -0.229 | 439,169 | 349,060 | 6.11% |
| adstock (**selected**) | 0.362 | 316,323 | 239,478 | 4.22% |
| adstock_saturation | 0.207 | 352,788 | 284,342 | 4.96% |

The baseline model performs worse than a naive mean predictor out-of-sample (negative R²), which is
expected — it ignores carryover and forces the regression to fit adstocked revenue effects onto
untransformed spend. The adstock model was selected under the documented selection rule (not R² alone):
it has the best test RMSE and MAPE of the three. The full adstock+saturation model does not out-perform the
adstock-only model out-of-sample here, likely because the additional saturation parameters add variance
that a 208-week dataset can't fully resolve — a legitimate, documented finding, not a modeling error.
